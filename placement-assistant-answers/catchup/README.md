# Catch-up checkpoints

Hand one of these to a student who is stuck when a part ends, so they can join the next part.
Each folder mirrors the kit: copy its files over the student's files with the same path.
None of them contains a lab answer.

| Folder | Hand out when | Replaces |
|---|---|---|
| `after-part1/` | Part 1 ends and TODO 1–3 aren't green | `app/tools/placement_tools.py` (notify_student stays TODO) |
| `after-part2/` | Part 2 ends and the agent tests aren't green | `app/agent.py` (memory wiring stays TODO) |
| `after-part3/` | Part 3 ends and the memory tests aren't green | `app/agent.py`, `app/memory.py`, `schema/agent.sql` (page_messages stays TODO) |

A student who took after-part3 also needs after-part1 if their tools weren't done.
